# TokenMonitor 1.14.1

- Usage Analytics opens with a weekly line chart. Choose Daily, Weekly, or Monthly, and keep that grain when changing the date range.
- Choose Columns to change the main trend. Lines connect measured buckets across gaps, and **Exact trend values** shows which buckets are missing measurements.

Use **Update and install** in Settings → About, then restart Codex. For manual installation, choose the package and SHA-256 file for macOS Apple silicon, Windows x64, or Windows ARM64. [Installation instructions](https://github.com/ACB-prgm/TokenMonitor/blob/main/docs/guides/installation.md)
