# Changelog

## 1.3.0 — initial public distribution

- Unified public version after native 1.2.0 and private Embedded 0.3.5.
- Preserves Embedded's context, cache, allowance, pricing, compaction, history,
  task selection and local telemetry behavior.
- Adds a prebuilt Apple silicon macOS release marketplace, integrity checks,
  isolated installation tests, version synchronization, CI and tag-driven releases.
- Adds public installation, updating, removal, privacy and contribution guidance.
- Applies PolyForm Noncommercial License 1.0.0 to original software and bundles
  third-party license notices.

## Historical development

Embedded 0.3.5 moved latest-call details above history and removed embedded task
locking. Earlier private 0.3.x releases added pricing, allowance estimates, bundled
runtime support and hook-discovery fixes. Native 1.2.0 is retired; its source and
Git history are retained for shared telemetry and legacy cleanup.
