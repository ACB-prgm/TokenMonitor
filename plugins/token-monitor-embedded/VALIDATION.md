# Validation scope

Automated checks cover collector accounting, parsing, history, pricing, compaction, allowances, UI behavior and packaging. Native package tests exercise the bundled runtime and launchers. Automated checks do not establish trusted desktop hook delivery or visual behavior.

Find the version matching this package in the [release records](https://github.com/ACB-prgm/TokenMonitor/blob/main/docs/releases/index.md). Each available validation record distinguishes completed checks from remaining platform and desktop verification.
