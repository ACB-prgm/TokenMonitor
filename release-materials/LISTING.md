# Listing

- Name: TokenMonitor
- Short description: Local and SSH Codex usage monitor
- Category: Productivity
- Publisher identity: supplied by owner and verified in OpenAI Platform before submission; do not infer from local machine account.
- Platforms: local Codex desktop on Apple silicon Macs, macOS 13 or later.

TokenMonitor displays cached, fresh and input context tokens, account allowance telemetry, estimated skills/tool context, cache temperature and compaction economics in a compact native floating window. Expand for recent-call history and details, choose a task manually, or follow the next supported hook event. Supports system light/dark appearance and corner snapping. Optional dedicated-key SSH connections show usage from other Macs, with machine-grouped tasks and connection status in Settings. Local monitoring remains the default.

The explicitly invoked setup skill installs a prebuilt companion app, six user hooks and a per-user event-driven launch helper. No Python, Xcode, remote MCP server or model calls are needed by the monitor. The initial release is ad-hoc signed and unnotarized; macOS first-open approval and Codex hook trust are required. Estimates are not billing guarantees. TokenMonitor is independent and is not affiliated with OpenAI.

Removing the Codex plugin alone does not remove the separately installed companion app. Use the skill's uninstall action or the app menu. Preferences are retained unless purge is explicitly requested.

Starter prompts:
1. Set up TokenMonitor.
2. Diagnose TokenMonitor.
3. Uninstall TokenMonitor.

Country availability and policy attestations must be selected by the publisher. This release does not select them on the publisher's behalf.
