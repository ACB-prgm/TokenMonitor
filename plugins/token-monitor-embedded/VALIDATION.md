# Validation scope

Version 1.6.0 adds selectable recent-call details, bounded activity excerpts, and revised compaction labels. Automated tests compare captured reference scenarios and cover pricing, attribution, compaction label boundaries, activity association and bounds, missing data, call replay, incremental files, SQLite contention, concurrent hooks, Windows path rules and MCP Apps integration. Browser checks cover pointer and keyboard selection, repeated-click clearing, activity rendering, escaping, and narrow layouts.

The package test exercises the native bundled runtime with developer tools removed from PATH, first-prompt and lifecycle hooks, checksum repair, direct tools, UI-only metrics and clean shutdown. Foreign-architecture packages are inspected for correct binaries, launchers, hashes and metadata; executing them requires the matching OS and processor.

The maintainer authorized deployment and preparation of the 1.6.0 GitHub release. The release remains a draft while native platform validation runs; Windows desktop interaction requires separate confirmation. Hook discovery alone does not confirm trusted hook delivery or desktop rendering.
