# Documentation lookup

1. Read [the documentation index](docs/index.md).
2. Read the authoritative page matching the task.
3. Follow source and test links to verify implementation details.
4. Use release history only for historical questions.

Update authoritative documentation with behavior changes in the same commit. Add new topics to the index. Keep current behavior separate from historical evidence. Run `npm run docs:check` before committing documentation changes. Link directly to canonical documents and keep focused Git commits; do not push without authorization.
