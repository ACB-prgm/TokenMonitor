# TokenMonitor 1.13.0

- Open **Token Monitor Analytics** from Codex’s main navigation or **Usage analytics** in the thread monitor’s Settings. Explore all imported local history or the last 7, 30 or 90 days, filtered by model, reasoning effort and project.
- Trend estimated cost, cost per call, context cost per call and cached input share. Inspect the same cost composition as in the thread monitor, with compaction shown separately and cost category coverage disclosed.
- Use **Your top models** to see total input tokens by model, the split by reasoning effort and each model’s four KPIs.
- Find high- and low-cost threads relative to peers with comparable model, effort and pricing. **How to improve** suggests experiments when measured context or reasoning costs support them.
- The dashboard starts in **Compact**. Choose **Comfortable** or **Large** under **View scale** to resize and reflow charts and cards.

Packages are available for macOS Apple silicon, Windows x64 and Windows ARM64. Existing local installations can use **Update and install** in Settings → About. For manual installation, use the matching `token-monitor-1.13.0-TARGET.zip` and SHA-256 file. Restart Codex after installation and review hook trust if prompted.
