# TokenMonitor 1.14.0 validation

Analytics tests exercise day, week, and month buckets and verify that changing the bucket size preserves the filtered totals. Package tests compare the bundled help references against the canonical documentation. A disposable Codex app-server profile checks that the installed skill is discoverable from outside the repository.

Protected-main CI and the tagged release workflow run package, installation, update, rollback, and discovery checks on macOS Apple silicon, Windows x64, and Windows ARM64. The release workflow verifies the recorded source commit and SHA-256 checksums for all six ZIPs. [GitHub Actions](https://github.com/ACB-prgm/TokenMonitor/actions)

Desktop rendering, trusted hook delivery, and automatic help skill selection in a normal chat require a separate check in Codex Desktop.
